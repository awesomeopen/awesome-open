# Awesome Open

> Awesome Open is a curated directory of software whose names begin with “Open”, organized by what the software does. It helps readers discover projects and follow links to their official repositories or websites.

The canonical repository is https://github.com/awesomeopen/awesome-open. The README is the source of truth for entries, descriptions, categories, and current metadata; this file is a navigation summary, not a separate catalog.

Eligibility is based on the software's own name: capitalization, spaces, and hyphens do not change eligibility. A documented expanded name can qualify an abbreviation, such as Open Broadcaster Software (OBS). An organization's name or a description such as “open source” alone does not qualify a product.

Open-source and proprietary software, paid products, hosted services, libraries, command-line tools, and archived projects are all in scope. There is no minimum star count. Inclusion is not an endorsement, a quality ranking, or a claim that a project is open source, free, actively maintained, or suitable for a particular use. Each project's official sources establish its current features, pricing, license, and maintenance status.

Entries are alphabetical within functional categories and can appear in more than one category. GitHub metadata shows repository creation date, last push date (UTC), a known SPDX license, and stars. Repository dates are not original launch or release dates. Unknown licenses are omitted; non-GitHub entries omit this generated metadata. Bold names identify the three highest-starred GitHub repositories within a category, independently of chart coverage.

Hacker News charts show matching story submissions over 24 completed UTC months, oldest at left, using one shared square-root scale. They measure attention, including criticism and controversy, rather than endorsement or sentiment. Coverage is a researched subset; missing charts do not mean no discussion. The contribution guide and evidence file explain matching, thresholds, limitations, and the exact reporting window. Statistics change; use the linked sources rather than treating this summary as a live snapshot.
