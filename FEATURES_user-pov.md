# Features from the user's point of view

What readers and contributors can do with Awesome Open*. The available features
below reflect `main` reviewed on 2026-10-19; selected features awaiting review or still being
planned are listed separately. Evidence and artwork coverage vary by project.

## Available: find software

- Open-named software catalog - Explore software with Open names or documented expanded Open names, including lesser-known, proprietary, hosted and archived projects.
- Browse on the web or GitHub - Read the field-guide website or the category-based README from the same curated collection.
- Plain descriptions - See what each project does before opening its record or visiting another site.
- Search as you type - Find projects by name, short description or reviewed alternative name without submitting each search.
- Flexible text matching - Search without matching capitalization or accents; each entered word must appear in the supported search fields.
- Reviewed name aliases - Find supported alternate or expanded names where they have been checked.
- Function categories - Browse tools by what they do, and follow a project's category links to related entries.
- Illustrated category navigation - Browse category artwork and project counts in the table of contents.
- Multiple categories per project - Find a tool under each relevant function without treating its repeated listing as a different project.
- Combined filters - Narrow a search with several criteria at once.
- Alternative-to filter - Find tools with a reviewed comparison to a particular product.
- License filter - Select a detected license, any known license, or unknown license information.
- Run-mode filter - Find reviewed command-line tools, desktop apps, local web apps, servers, libraries or firmware where setup evidence exists.
- Install-method filter - Find reviewed installation paths such as downloads, installers, containers, package managers or source builds.
- Missing setup facts filter - See projects whose run mode or installation method has not been recorded, without mistaking missing evidence for lack of support.
- Minimum-stars filter - Set a minimum observed GitHub star count when that is useful to your search.
- Repository-push date filter - Find repositories pushed on or after a chosen date.
- Repository-push windows - Select pushes within 90 days of the data snapshot, more than two years before it, or an unknown date.
- Metrics-availability filter - Separate projects with cached repository metrics from those without them.
- Three sorting choices - Browse by name, most GitHub stars or latest repository push; unknown counts and dates come last.
- Reset filters - Return to the unfiltered, most-stars-first view with one control.
- Announced result count - Hear how many projects match the current selection when using a screen reader.
- Empty-result guidance - Know when nothing matches and how to broaden the search.
- Shareable searches - Copy a URL that preserves the search, filters and sorting.
- Back and Forward support - Revisit earlier selections using the browser's usual controls.
- Category star leaders - Spot the three highest-starred entries in each category without treating that rank as a quality recommendation.

## Available: inspect a project

- Expandable project records - Open details in the catalog while keeping the surrounding list in view.
- Direct record links - Share a project's catalog position or open its full record on a separate page.
- Scannable project links - Open a project permalink on another device by scanning the QR code on its record.
- Hidden-project notice - Know when a directly linked project is hidden by your current filters and how to reveal it.
- Stable project identity - Keep distinct projects separate even when they share a name; a display-name change keeps its catalog link.
- Official-source links - Go directly to the project's official repository or website to investigate further.
- Reviewed Function summaries - Read a fuller explanation of capabilities and intended use where a source-reviewed summary is available.
- Sourced feature notes - Discover an additional concrete capability on illustrated records that have reviewed feature notes.
- Repository timeline - Compare repository creation, latest recorded release and last push on one dated timeline; creation is not presented as the project's founding date.
- Repository dates - Read the actual recorded creation and push dates.
- GitHub archive flag - See when a repository owner has marked it archived, without treating that flag as a safety or quality verdict.
- GitHub stars - See the observed count without treating popularity as proof of quality or suitability.
- Detected license - See the reported license or an explicit Unknown, then check the project's current terms yourself.
- Latest recorded release - Follow the release tag and publication date when release evidence is available.
- Reviewed alternatives - Read the specific comparison, its source and its review date.
- Setup overview - Check reviewed ways to run and install a project before leaving the catalog; coverage is currently a small pilot.
- Platform details - Read supported operating systems or architectures with the qualifications recorded by the source.
- External-service requirements - See whether a recorded service is required, optional or dependent on configuration.
- Package details - Inspect recorded package names, distribution channels and upstream or community relationships.
- Resource requirements - Read sourced minimums, recommendations and constraints with their workload or version limits.
- OpenSSF Scorecard details - Inspect available automated security-practice checks, reasons, scan date and coverage without treating them as a security guarantee.
- Retry record loading - Try again from the record if its details fail to load, or follow the full-record link.
- Read or print a full record - Use a dedicated evidence page when you want to print, browse without JavaScript or recover from a detail-loading failure.

## Available: understand attention and evidence

- Hacker News sparklines - Scan matched story activity over two years where a project has tracked HN evidence.
- Hacker News source links - Follow the linked search to investigate the discussions behind the counts.
- GitHub star-history charts - View monthly retained-star observations for covered repositories, separately from today's star total.
- Aligned attention windows - Compare GitHub and HN charts over a shared month window where both datasets support it.
- Separate attention signals - Inspect stars and HN activity independently; neither is labeled adoption, sentiment or quality.
- Source and review dates - See where reviewed summaries, comparisons and setup facts came from and when they were checked.
- Retrieval history - Inspect available provider sources, successful-fetch dates and later collection attempts.
- Stale-data labels - Recognize retained older observations after an unsuccessful update.
- Explicit unknowns - Distinguish unavailable or unchecked information from a real zero or a negative finding.
- Background data refreshes - Receive updated repository facts and due optional evidence through the existing publisher, without refreshing each project yourself.
- Snapshot date and source revision - Identify which edition of the collection you are reading.
- Downloadable evidence - Inspect the underlying catalog, comparison and chart evidence.
- Retained chart observations - Consult the [repository archive](data/chart_observations.json) for saved chart evidence from earlier collections.

## Available: explore the specimen world

- Original specimen illustrations - Explore function-led artwork alongside factual project descriptions where approved illustrations exist.
- Artwork magnifier - Inspect illustration details with a mouse-hover lens or a tap-to-toggle lens on touch screens.
- Enlarged specimen studies - Examine selected details alongside the full illustration.
- Illustrated record plates - Inspect the artwork, function, available facts and source links together in one expanded record.
- Seven-specimen jar display - Discover seven illustrated projects in the catalog's photographic glass-jar display.
- Interactive jars - Reveal project callouts, crack the glass through successive activations and continue to the full record.
- Jar callouts - Read a short function description and available stars and license information before inspecting a project.
- Pause and resume motion - Stop decorative movement while reading and restart it when you want.
- Small-screen jar browsing - Scroll the jar display horizontally on narrow screens.
- Weekly Spotlight - Discover seven distinct illustrated projects through a reproducible weekly random draw, independent of star counts.
- Repeat-appearance cooldown - Get more variety because recently drawn projects sit out four subsequent display weeks.
- Last-complete-edition fallback - Keep a complete illustrated selection when a new draw cannot be published, labeled with its original week.
- Spotlight archive - Revisit published weekly selections, with saved names, descriptions and categories.
- Spotlight totals - See the current edition, number of editions, distinct projects shown and eligible illustration count at the last draw.
- Permanent edition links - Share a particular Spotlight week directly.
- First and returning appearances - See whether a specimen has appeared in an earlier published draw.
- Inspectable draw records - Check the saved selection details or download the published draw records.
- Changing footer artwork - Encounter a different decorative footer illustration when reloading the catalog page.

## Available: examine the collection in Observatory

- Collection overview - See project totals, observed stars and other snapshot measures in one place.
- Category distribution - Explore how tools are distributed across functions, with overlapping category memberships kept distinct from unique-project totals.
- License distribution - Compare detected licenses while keeping unknown licenses visible.
- Repository age and recency - Explore repository creation, push and release dates without inferring project health.
- Star concentration - See how much of the observed star total belongs to the highest-starred projects.
- Duplicate and variant names - Find separate projects with identical names or reviewed grouping rules for case, spacing, hyphen and underscore variants.
- Name-difference highlights - See which letters, spaces or separators differ within Observatory name groups.
- Reviewed rhyming names - Explore a small set of names that rhyme under the stated pronunciation assumptions; unreviewed names remain unclassified.
- Observatory filters - Restrict charts, project rows and name groups by category and license.
- Shareable Observatory selections - Preserve a selection in the URL and revisit it with Back and Forward.
- Chart data tables - Read the exact values behind each visual chart in a foldout table.
- Full project data table - Inspect the selected records behind the summary.
- Evidence-coverage overview - See where the whole collection has usable, partial, stale or missing supporting data.
- Selection CSV export - Download the currently selected Observatory rows for further analysis, with source and snapshot information.
- Observatory snapshot download - Retrieve the collection's structured snapshot and aggregates.
- Offline Observatory report - Download a self-contained report for reading and filtering without a connection; external sources still need the internet.

## Available: read, navigate and reuse

- Phone-friendly records - Read wrapping details and use the catalog on narrow screens.
- Keyboard controls - Reach search, filters, disclosures and jar interactions without a mouse, with visible focus.
- Skip-to-content navigation - Bypass repeated navigation and reach the main content directly.
- Reduced-motion support - Use the site with a reduced-motion preference without losing the underlying project information.
- Labeled controls and status updates - Use accessible control names and announced result counts when navigating with assistive technology.
- Text equivalents for charts - Read chart labels, descriptions or data tables.
- No-JavaScript reading - Browse all projects and follow full-record links even when interactive search and filtering are unavailable.
- Offline catalog download - Keep one self-contained HTML file with records, artwork, fonts, charts and embedded evidence; external project links still need a connection.
- Catalog JSON export - Reuse structured project records and evidence in your own analysis or tools.
- Local search and filters - Change your selection within the downloaded catalog index without a server round trip for each query.
- On-demand record loading - Start with the list and load full evidence when opening a record.
- Locally bundled fonts and assets - Read the exported guide without relying on an external font service.
- Catalog, About and Observatory navigation - Move between browsing, the collection's explanation and its statistics.
- Return-to-top link - Get back to the catalog from the footer without scrolling through the entire collection.
- Reusable catalog content - Reuse the list under CC0-1.0 while respecting the separate licenses of listed software, fonts and artwork.

## Available: contribute and follow the work

- Submit a project by pull request - Propose a qualifying tool with its official source through the linked contribution guide.
- Small corrections welcome - Suggest description, category, link or evidence fixes without needing a large contribution.
- No popularity threshold - Propose lesser-known or new Open-named projects without a minimum star count or release age.
- Daily discovery work - Add Open-named software verified against official sources through the authorized source-only discovery task; publication follows successful repository checks and the publisher. Artwork, summaries and alternative mappings remain separate draft-PR proposals. See the [automation inventory](automation/README.md).
- Reviewable evidence updates - Examine proposed summaries, comparisons, setup facts and artwork before they enter the published collection.
- Downloadable pull-request previews - Inspect proposed README and field-guide output before a change is merged.
- Public source and change history - Inspect how the catalog is built and follow proposed or accepted changes on GitHub.
- Dedicated design guides - Contributors can use the project's interface and illustration skills to extend its visual language consistently.
- Support link - Follow the optional coffee-support link from the catalog footer.
