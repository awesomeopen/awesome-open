## Local vectors and generated ownership

`scripts/readme_badges.py` defines the flat-square vector geometry and typography.
The static `site/brand/browse-catalog.svg` is generated by
`flat_badge('Browse catalog')`; it contains only a rectangle and ordinary text.
Its bytes are recorded by the brand asset inventory.

`assets/readme/specimen-count.svg` is a generated output. The README renderer
uses the catalog's existing canonical-URL normalization and curated row grammar
to compute the count offline. The initial SVG accompanies this renderer extension;
subsequent changes belong to the existing serialized publisher. Never hard-code a
count in `README.source.md` or use category memberships, GitHub-only entries or
the number of drawings as the specimen total. The count is 511 on the source
baseline `bde34ad7ac4740124e9e9279f2e902d19fab34df` (533 category memberships).

Offline README previews include the local Browse badge, generated count badge and
unchanged banner. The Publish badge remains a live remote status image. Publisher
validation compares the count SVG against a fresh offline render before allowing
a generated-only commit. Its permitted path is exact; no broader asset-write
permission, workflow, credential or repository-setting change is needed.
