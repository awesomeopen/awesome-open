# Current rankings with measured history

The Scoreboard keeps one current set of Top 10 tables and metric-specific plate
trophies. The heading and plate label show the snapshot's actual update date.
Weekly freezing remains the publisher rule; there is no list of weekly pages or
collection of past trophies.

Native **Over time** disclosures add a small, optional evidence view beneath each
board. Up to three projects from the current table are shown. Star totals and
release-to-push gaps use actual saved captures on a 12-month scale. Creation
dates, rename occurrences, streak dates and monthly HN counts retain their own
meanings. Single points, missing measurements and unavailable legacy detail have
distinct representations; approximate rename dates remain textual evidence.

This partially evolves [B-PR227-01](B-PR227-01.md), preserving the six metrics,
competition ranks, weekly freeze and current-table/plate consistency. It retains
the compact row treatment from [B-PR234-01](B-PR234-01.md). The instrument layer is
a ruled table with restrained native SVG measurements; specimen artwork,
navigation and the Spotlight selection are unchanged.

The existing publisher saves compact all-eligible measurements alongside the
current rankings, with source dates, coverage and deduplicated provenance. The
legacy Top 10 remains an explicitly partial observation. Prior facts are not
reconstructed from today's cache. Generated snapshot changes remain publisher-owned.

See [Scoreboard method](../../site/SCOREBOARD.md) for schema, source and publication
rules. Validation is recorded in the pull request; this proposal does not claim
owner visual review or live publication.
