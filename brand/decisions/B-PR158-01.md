# Fixed evidence grid below the specimen plate

Owner-directed course change. Recent attempts to tie the expanded record together
visually did not work; the owner sketched a new lower half and reviewed three
rounds of mock-ups. The upper half of [B29](../decisions.md) stays: function
statement and prose, specimen, label, feature notes. Below it, the stacked bands
numbered by presence become a fixed grid of boxes, reminiscent of a bento box and
a specimen display case. This changes B29's band order, numbering, label colour
and evidence columns, and the content of the rename popup from
[B-PR150-01](B-PR150-01.md). Their other rules stay, so the supersession list is
empty.

## Grid

- Eight columns on desktop. Rows, top to bottom:
  - **II / Repository record:** GitHub stars, Detected license, Repository
    created, Repository push (two columns each), then the timeline across the full
    width.
  - **III / Observations & evidence:** GitHub stars sparkline, Hacker News
    sparkline, an empty box, OpenSSF Scorecard.
  - **IV / Release record:** GitHub release (two columns), an empty box (three);
    **V / Where it runs** (three).
  - **VI / Reviewed alternatives:** its own grid in thirds, one alternative per
    third.
  - **In the wild:** the existing departure, full width.
- Section numbers are fixed. The grid is stable: with no data every box stays in
  place at the same size. The alternatives row is the only one that disappears.
- The timeline box keeps its height when it has dates and collapses to one line,
  "Repository timeline: Unknown", when it has none.
- Empty boxes are reserved for future evidence sources: solid
  `--rs-verdigris-art`, no content, hidden from assistive technology. They stay
  inside their row's grid cells.
- Boxes: white, 1px `--rs-blueprint` border, 2px radius, compact padding, on a
  `--rs-mist` panel padded 32px (24px below 1100px, 16px below 720px). Below
  1100px the grid has four columns and alternatives two; below 720px everything is
  one column and the empty boxes are hidden.
- Vertical rhythm: boxes are short and wide. As a direction, the upper half and
  the lower half each take roughly one desktop screen. A Function statement over
  90 characters steps down to 24–30px to keep the upper half near that.

## Box content

- Anything not known reads "Unknown". The reason ("Not checked", "No result
  returned", "Not reviewed", "No GitHub repository mapped"), provider status
  ("Cached", "Unavailable", "Partial") and the "past 2y" window move into the
  box's popup.
- Popups open from a bare "i" in the box corner (`control.info` in the
  [icon map](../icons.md), currently planned). Until the icon is drawn and the
  popup behaviour is settled, the trigger is a native disclosure.
- Serif values use Półtawski Nowy at 33px (Unknown at 28px), inside the 28–42px
  headline range. The GitHub release version is centred in its box.
- The two sparklines share one baseline. Each sits on a single small line,
  `33 · 2024-10 – 2026-09`, with non-breaking spaces and hair spaces around the
  en dash, which never wraps. The full count ("33 submissions / past 2y"), scale
  and sources are in the popup. Box titles drop "/ past 2y".
- Where it runs drops its title and the Run / Install / Documented platforms
  words, which remain for screen readers. Chips are filled per line:
  `--rs-amber` for run modes, `--rs-trace` for install methods,
  `--rs-emerald-art` for platforms, all with `--rs-ink` text (5.8:1 on emerald-art, higher on the others). The chip
  text carries the meaning; the popup starts with a colour key.
- Alternatives drop the "Reviewed alternative" line, which repeats the section
  label. "Checked 2026-10-03" follows the scope text inline, with a non-breaking
  space after "Checked".
- The rename popup on the timeline shows the sources line only. The text before
  it and the reviewer's name are dropped.

## Colour changes

- Section labels inside the grid (II–VI) are `--rs-muted` blocks with
  `--rs-mist` type (6.9:1), replacing B29's scarlet. "I / Function" and "In
  the wild" keep scarlet.
- `mark.tool-name`, the project name highlighted in the function prose, uses a
  `--rs-scarlet` ground with white type (6.4:1) instead of `--rs-blueprint`.
- `--rs-verdigris-art` (empty boxes) and `--rs-emerald-art` (platform chips)
  gain these interface fills. Both were documented for artwork only; neither
  carries text colour here.

## Evidence and limits

The owner's sketch, three mock-up rounds and their review are summarised here
rather than published as a conversation. The study is in
[`brand/studies/plate-grid/`](../studies/plate-grid/README.md): a generator that
rewrites the generated record pages, and cropped screenshots of OpenTofu (fullest
record), openstatus (three alternatives) and OpenGeoSys (sparse, not on GitHub)
at 1440px, plus OpenTofu at 390px. Data comes from the site generated at main
`8222e21`.

No record has every evidence type. OpenTofu lacks a returned Scorecard result, so
the mock-up shows the filled Scorecard box with OpenSCAD's values. The generator,
stylesheet, ledger drawer, standalone and print output are unchanged; the
implementation PR must update `scripts/build_site.py`, `site/styles.css` and the
browser checks, compare the result with the study box by box, and move the
`control.info` icon row from planned to today when the popups ship.

## Implementation

[#166](https://github.com/awesomeopen/awesome-open/pull/166) builds the grid in `scripts/plate_grid.py`, renders it from
`scripts/build_site.py` and styles it in `site/styles.css`; the browser checks
cover it at 1600, 1440, 900, 768, 390 and 320px. Built at main `9033749`,
OpenTofu, openstatus and OpenGeoSys at 1440px and OpenTofu at 390px match the
study box by box: rows, spans, fixed section numbers, reserved boxes, "Unknown"
values, the collapsed timeline and the alternatives in thirds. Changed from the
study:

- **Departure host:** OpenGeoSys reads "Explore OpenGeoSys on GitLab".
  [#157](https://github.com/awesomeopen/awesome-open/pull/157) (recognized
  repository hosts) merged after the study.
- **Timeline height:** a dated timeline sizes to its labels (about 166px for
  OpenTofu, 132px for openstatus at 1440px); the study drew both at about 196px.
  It collapses only without dates.
- **Phone section labels:** below 720px the II–VI labels sit above their first box
  instead of inside its top edge.
- **Row labels at narrow desktop widths:** between 1101 and about 1150px the
  "III / Observations & evidence" label is wider than the two-column GitHub stars
  box and runs past it over the empty lane above the row. Labels stay inside the
  grid.
- **Popup side:** each popup opens from the box edge nearest the grid's centre,
  measured when it opens, because the four-column layout moves boxes between
  sides. "Where it runs" popups are at most as wide as their box, and below 720px
  every popup is.
- **Icon status:** `control.info` stays planned in the [icon map](../icons.md).
  The trigger is a typeset "i"; the row lists the plate popups as a use until the
  SVG is drawn.
