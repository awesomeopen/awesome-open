# Separate reviewed rhyming-name measure

[PR #119](https://github.com/awesomeopen/awesome-open/pull/119) adds a clickable
native disclosure below Shared names. It is a separate measure, not a new
identity category or an addition to the shared-name headline. A canonical project
can occur in both measures; the displayed explanation says totals are not additive.

The [Observatory contract](../../site/OBSERVATORY.md#reviewed-rhyming-names)
defines the reviewed single-syllable English subset, grouping, exclusions,
validation and filtering. [Source records](../../data/name_rhymes.json) preserve
exact current names, canonical URLs, ARPABET readings, date, reviewer and the
editorial-assumption basis. Official project links establish names, not verified
brand pronunciations. Unreviewed names stay unclassified.

Uses existing typography, palette, native disclosures, focus treatment and
responsive list wrapping. No new icon, illustration, artwork role, reusable-skill
change, external pronunciation service, collection or workflow is introduced.
Aliases remain search-only for this measure; no registry identity or HN matching
changes. Speech playback is outside this proposal.
