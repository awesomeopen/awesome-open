# Consistent navigation and compact Spotlight editions

[PR #233](https://github.com/awesomeopen/awesome-open/pull/233) implements the
user-directed Catalog footer sequence: Submit a project, Observatory, Scoreboard,
Spotlight, GitHub, Top. Observatory, Scoreboard and Spotlight headers share the
sequence Catalog, Observatory, Scoreboard, Spotlight, marking the active route.
This updates the navigation portion of B42 and B-PR134-01.

Every Spotlight edition uses the compact tray formerly used for earlier editions:
seven columns on desktop, four below 1000px and three below 640px. Rows show
illustrations, names and categories. Metadata uses 10px type and -0.05em
letter-spacing. The saved descriptions remain in draw evidence; appearance
status is omitted from the visible rows. Edition labels and draw details retain
their existing presentation.

Validation: offline site build, 40 weekly draw/Scoreboard tests and 30 Observatory
tests pass. Generated navigation links were inspected for order and active route.
Browser visual verification remains for CI and review.
