# Shared cube-root scale for HN sparklines

Use one shared cube-root vertical scale for monthly HN story counts. Equal counts
keep equal heights across projects; zero-count months stay empty. The largest
monthly count still reaches the same full bar height.

This increases visibility for sparse histories while compressing differences
between high-volume months. At a shared maximum of 160 stories per month, one
story grows from about 1.1 to 2.5 pixels at the 80-pixel desktop chart width.

[PR #319](https://github.com/awesomeopen/awesome-open/pull/319) updates the
[HN method](../../CONTRIBUTING.md#hacker-news-attention-sparklines) and
[visual guide](../../site/RETRO-SCRAPERISM.md#sheet-refinement--hn-and-metadata).
It changes only the scale described in [B-PR211-01](B-PR211-01.md); chart
eligibility, matching, counts, collection windows and linked searches retain
their existing rules. GitHub star-history charts retain their own scale.

The existing publisher regenerates README and website charts from this source.
