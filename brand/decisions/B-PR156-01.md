# Illustrated shared-name comparisons

User-directed implementation in [PR #156](https://github.com/awesomeopen/awesome-open/pull/156):
reuse each project's approved specimen illustration beside its source and short
description, with the group heading and project names centered. Put Catalog in
the regular definition list, with a linked Registry ID as its value.

The comparison lets readers compare visual interpretations of similarly named
tools. It does not assert shared purpose, origin or a relationship. Preserve
original artwork bytes, alt text and proportions; no placeholder for missing art.
Apply the same rendering to server output, filtered results and offline reports.

Mock comparison: outer-edge artwork and paired facts are retained. Group
metadata moves to its own centered line so it cannot displace the shared heading.
Both the shared heading and individual project names are centered. The requested
Catalog fact replaces the mock's separate Ledger record link. Mobile records
stack to retain readable descriptions.

Source baseline: `14b4f76fc220a7629c9849c0b318316b10e830f4`.
Static build and Observatory contract checks cover server output and offline
embedding. Browser visual verification was unavailable: Chromium's download
failed in the execution environment. Artwork provenance and skill pins are
unchanged; the asset index records the new display role.
