# Reviewed plural names in Spelling variants

Place OpenTask / OpenTasks in the existing Spelling variants group with a
Plural tag. Highlight the differing suffix using the existing scarlet letter
mark. Keep one matching key per display name and count each canonical project
once. Filtering retains a group only while two distinct projects remain.

The reviewed mapping is `opentasks` to `opentask`, after the usual case and
separator normalization. Further plural matches require explicit review. This
extends the shared-name grouping described in B31; rhyme keys, catalog IDs,
source URLs and alias evidence retain their existing behavior.

[OpenTask](https://github.com/AristideDongo/opentask) is a self-hosted teamwork
application. [OpenTasks](https://github.com/dmfs/opentasks/blob/3ccb6f9d0195795bd461c3e634bbb8b22c72932c/README.md)
is an Android task app. Each keeps its own record and description. The
[Observatory contract](../../site/OBSERVATORY.md) documents the matching rule.

[PR #219](https://github.com/awesomeopen/awesome-open/pull/219) contains the
implementation and regression checks for both rendering paths, filtered groups,
case/separator tags and unreviewed plural lookalikes.
