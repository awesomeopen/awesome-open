# Reviewed aliases directly below the plate heading

Place reviewed alternate names immediately below the existing Field notes / folio /
project heading. The first line reads “Also known as: [name]”; every additional
name occupies its own line. Each name links to its reviewed official source.
This implements the owner's requested placement in both drawer and full-record
plates, using the shared renderer. It leaves the canonical heading unchanged.

Use compact Commit Mono text in the existing muted colour, with natural wrapping
on narrow screens. Omit names that normalize to the current display name and
omit the entire block when none remain. Preserve those names in curated evidence
and search. The [alias contract](../../site/PROJECT-ALIASES.md) owns the evidence;
this display adds no alias classification, rename dates or HN attribution.

The implementation and review evidence are in [PR #210](https://github.com/awesomeopen/awesome-open/pull/210).
The existing specimen, Function content and evidence grid retain their positions
relative to one another. No artwork, assets, tokens or curated records change.
