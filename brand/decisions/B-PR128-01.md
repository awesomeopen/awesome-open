# Compact Catalog rows and patterned departure bands

User-directed changes implemented for review in [PR #128](https://github.com/awesomeopen/awesome-open/pull/128),
based on source `c9fd739e95d7cb7f0b5c84c7c188305363f03c6f`:

- Remove the explanatory snapshot/setup note beneath Filters from the generator.
- Add 4px left padding to folio numbers.
- Remove both base summary padding/min-height declarations and responsive padding
  overrides, so narrow screens retain the requested compact spacing.
- Reuse `patterns/navypattern2.png` as the repeating departure background. Keep
  the seeded, decorative contour SVG above it; the SVG encodes no project data.

This refines B29’s departure treatment without replacing the specimen plate.
Existing filter semantics, factual evidence, assets and contour generation remain
unchanged. The pattern’s role is recorded in its existing provenance and asset
index; no asset bytes or pinned skills change. Main, static records and standalone
output share these styles; existing standalone CSS embedding covers the reused URL.

Validation: brand integrity, site build tests and Catalog JavaScript tests.
Browser visual checks are unavailable in this execution environment.
