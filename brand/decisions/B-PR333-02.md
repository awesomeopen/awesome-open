# Short category names with stable category IDs

The 21 category headings in `README.source.md` use short names: AI, Commerce,
Socials, Creative, DBs & Search, Dev Tools, Education, Finance, Gaming, Health,
Home, Infrastructure, Knowledge, Maps, Networking, OS & Firmware, Productivity,
Hardware, Science, Security and Storage. The README, the Catalog rail, plate
labels ("Domain: AI"), the Observatory and the Spotlight show the same names.

Each category keeps the ID its longer heading produced (for example
`ai--language-models`) through `CATEGORY_IDS` in `scripts/build_catalog.py`, so
`?category=` links, category artwork and stored evidence stay valid. README
anchors follow the new headings (`#ai`); plate domain links use them.

Rationale: owner direction (2026-11-11) for the three-column Catalog rail, where the
long names did not fit. See [B-PR333-01](B-PR333-01.md).
