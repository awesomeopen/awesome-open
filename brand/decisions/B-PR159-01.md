# Artwork backfill batches of up to 40 projects

The owner directed an increase from 20 to 40 distinct canonical projects per
artwork backfill batch on 2026-10-21. This changes the batch cap in the
[specimen handoff](../../site/SPECIMEN-ART.md#build-behavior) and
[automation inventory](../../automation/README.md#backfill-specimen-artwork).
[PR #159](https://github.com/awesomeopen/awesome-open/pull/159) records the
repository reconciliation. The hosted prompt update was verified separately
on the same date; the task remains enabled with its existing daily, nominal
08:00 America/New_York flexible schedule.

Descending cached-star order, at most one batch awaiting user review, existing
artwork exclusions, actual image generation, source and generation provenance,
required technical and safety checks, matching cut-outs, and the prohibition on
paid fallbacks all remain in effect. New artwork retains the existing display
approval policy; merging remains a separate owner decision.

This cap is an upper bound, not evidence that a 40-image batch has completed.
The next generation run will establish how the larger batch behaves under the
available generation limits. No artwork is generated by this documentation
change, and the separate star-history batch limit is unchanged.
