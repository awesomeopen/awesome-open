# Hide the full-record fallback while a drawer loads

The owner requested removing the brief full-record link flash before a fetched
plate appears. Hide the fallback as soon as enhanced loading starts, retain the
live loading status, and keep the link hidden after success. Restore it on failed
loading, cancellation or eviction. Static HTML keeps the visible link so disabled
JavaScript or a script download failure never removes access to the record.

Use the native hidden attribute and return focus to the summary before hiding a
focused fallback. This partially changes the loading-state visibility in
[B-PR112-01](B-PR112-01.md); its successful-load behavior and the fallback purpose
in [B-PR111-01](B-PR111-01.md) remain intact. No artwork, evidence, retention or
native disclosure behavior changes.

Implementation and validation: [PR #125](https://github.com/awesomeopen/awesome-open/pull/125)
and the [loading contract](../../site/DETAIL-LOADING.md). Deterministically held
responses test the hidden loading state; errors, blocked runtime downloads and
no-JavaScript browsing test recovery access. Physical-device validation remains
separate from Chromium mobile/touch emulation.
