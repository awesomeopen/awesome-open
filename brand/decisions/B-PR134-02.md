# Move the fifth jar between the second and third

User-directed addition to [PR #134](https://github.com/awesomeopen/awesome-open/pull/134):
move the original fifth vessel (bail jar) between the second (square cork) and
third (shouldered). The new left-to-right order is original jars 1, 2, 5, 3, 4, 6, 7.

Reorder the complete rendered exhibits so images, current occupants, labels,
links and controls move together in visual and keyboard order. Preserve the
original slot indices for specimen-fit assignment; no redraw or reassignment is
caused by the move. Shift the narrower grid column with the tall vessel at all
three existing breakpoints, keeping the overall widths and vessel geometry.

This partially updates B38’s fixed order and the original height-ordered
composition; the weekly selection rules, artwork, vessel dimensions, lighting
and interactions remain unchanged. No asset bytes or pinned skills change.

Validation covers rendered jar order, occupant-to-vessel preservation, production
hero/offline assets and existing weekly draw/fit tests. Browser visual checks were
unavailable in this environment.
