# Spotlight route, ISO week anchors and page cleanup

User-directed implementation for review in [PR #134](https://github.com/awesomeopen/awesome-open/pull/134),
based on source `8452317d280458ab9c8061fe33947a9fd860a589`.

Move the weekly archive from `/draws/` to `/spotlight/` across the Catalog,
static record navigation and hosted link in the standalone download. The archive
JSON is now `/spotlight/draws.json`. Edition headings, links and the current-edition
metric use ISO week years/numbers, with two-digit weeks: the display week beginning
2026-10-19 is `2026-W43`, linked at `/spotlight/#2026-W43`. ISO week years govern
the label even when they differ from calendar years.

On Spotlight only, remove the scope block and the entire How the draw works
section, hide `nav.obs-jump`, remove Observatory links from header/footer and
remove Return to project ledger from the footer. Put Download draw records ·
Draw contract on one footer line immediately above GitHub. Keep the specimen
trays, metrics, folded draw records, closing mark and patterned footer.

This partially changes B38/B44’s archive presentation and
[B-PR107-01](B-PR107-01.md)’s route naming. Existing decision records remain
historical. Draw selection, cooldown, saved dates, source records, assets and
pinned skills are unchanged. This is a route migration; old `/draws/` URLs and
`#week-YYYY-MM-DD` fragments are no longer emitted.

Validation covers pending-edition exclusion, ISO year boundaries, page structure,
footer order, generated links, offline assets and the weekly hero. Browser visual
checks are unavailable in this environment.
