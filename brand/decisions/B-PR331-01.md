# Download reviewed setup evidence

The Catalog footer adds “Where it runs (data)” between Comparison evidence and
Catalog JSON. It downloads one compact schema-1 document of approved deployment
records, keyed by full canonical project ID, with scopes, sources and review
provenance intact. The label matches the specimen plate's setup section.

This implements the owner-authorized [Phase L plan](../../automation/backfill-deployment-evidence.md#20-implementation-roadmap)
and its [download contract](../../site/DEPLOYMENT-EVIDENCE.md#downloads).
Catalog deployment fields keep the filter values, review status/date and static
record link. Full HTML setup disclosures and the existing evidence layout remain
unchanged. The 4 KiB catalog budget and 100 KiB backfill guard remain in force;
the combined download has its own 3 KiB-per-catalog-record budget.

No asset, token, icon, collection or source-review rule changes. Owner review and
merge remain required.
