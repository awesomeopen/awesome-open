# Remove the Observatory report and project data table

Owner-directed on 2026-10-22, when reviewing the open items of the
[performance PRD](../../PRD/2026-10-22_Performance-tuning.md#w4-payload-reduction-phase-3).
The Observatory stops generating `observatory/report.html` and drops its
“Download standalone report” link. The folded “Data table” of project records
in the Project data section is removed as well. The section keeps the selection
CSV and snapshot JSON downloads; `observatory/projects.csv` and
`observatory/snapshot.json` carry every per-project field the table showed,
including the metrics and release cache times.

The report used the same embed-everything pattern as `standalone.html`
([B-PR176-01](B-PR176-01.md)): 9.8 MiB of base64 artwork, fonts and downloads
built from the page after it was rendered. Both are removed in the same PR, so
the site has no single-file download left.

## What changes

- [B22](../decisions.md): the “Data table” disclosure and the report download
  are gone, and the report no longer shares the treatment. The voice rules,
  visible CSV/JSON downloads and no-JavaScript view stay.
- [B31](../decisions.md): the folded project listings are the name-group plates
  only. The rest of the redesign stays, so the supersession list is empty.
- [B-PR176-01](B-PR176-01.md) said the Observatory report was unchanged; this
  record replaces that sentence.
- `site/OBSERVATORY.md`, `site/OBSERVATORY-REDESIGN.md` and
  `site/RETRO-SCRAPERISM.md` describe the Project data section as downloads.
  The design reference lists the single-file downloads and the data table as
  retired.
- [Icon map](../icons.md): `link.download` keeps “Download selection CSV”.
  `view.table` keeps its drawing and provenance and currently has no label or
  use on the site.
- Print hides the Project data section, because its download links are hidden
  in print.

The per-chart “Chart data” tables stay; they are the accessible equivalent of
each bar list.

## Status

Implemented in [PR #184](https://github.com/awesomeopen/awesome-open/pull/184),
together with [B-PR176-01](B-PR176-01.md).
