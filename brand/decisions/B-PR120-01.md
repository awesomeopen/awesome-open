# Propose function-derived specimen voices and an offline audition pilot

The [voice feature plan](../../site/SPECIMEN-VOICE-PLAN.md) records the requested
direction: independently described fictional voices derived from official project
functions, pre-generated name and plate audio, and an always-available neutral
option. Stock fictional narrators remain a fallback. Spoken factual copy retains
the [foundation](../foundation.md) editorial rules; the proposed strangeness belongs
to the sound. Existing illustration review policy does not approve audio.

[PR #120](https://github.com/awesomeopen/awesome-open/pull/120) proposes documentation
only. Neither this record nor a documentation merge establishes an implemented
voice pipeline, a model winner, permission to expose a local backend, or an audio
publication review. The plan links primary model sources and labels the supplied
short-utterance rankings and warm-up claims unverified pending actual auditions.

The first pilot uses offline batch exchange, repeatable direct/carrier comparisons,
alignment-assisted crops followed by listening, and retained original audio and
provenance. Breeze TTS 2 remains licensing-gated for production consideration.
Implementation, asset/schema design, budgets and model selection follow evidence
from the pilot in a separate review. No existing decisions are superseded.
