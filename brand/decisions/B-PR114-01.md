# Compose specimen fields from stored visible bounds

[PR #114](https://github.com/awesomeopen/awesome-open/pull/114) addresses excessive
vertical whitespace around short, wide illustrations and the detached contour
floor. It partially refines B29's field geometry; its specimen concept, evidence,
original assets, feature notes, loupe and motion policy remain unchanged.

Use the committed cutout subject bounds at build time. Keep the current 627px
canvas-width cap and proportional narrow-screen downscaling. Retain 8% of source
height above and below the measured subject (limited by the source edges), then
size the field to that retained vertical extent. The full image still renders:
there is no raster edit, hard clipping, browser pixel scan or subject enlargement.
The margin is a conservative layout allowance, not a claim that the alpha > 0.5
bounds include every faint shadow. Visible overflow retains outlying marks.

Align the contour center to the subject baseline; its fade remains in the lower
half. Feature leaders begin just below that same baseline. Keep the identity
label in the specimen column so neighboring prose cannot stretch the gap.
Missing or malformed bounds use the full canvas. Missing/stale cutouts retain
the original-image fallback without terrain. No-art records keep no placeholder.

The layout is emitted in HTML/CSS for static records and standalone output as
well as lazy-mounted drawers. The existing full-source loupe/crop coordinate
system remains, with independent width/height handling for non-square sources.

Validation covers stored-bound extremes, 1024px/1254px sources, invalid metadata,
eight responsive widths, label/terrain geometry, loupe alignment, no-JavaScript,
standalone and the existing lazy-drawer tests. CI captures wide-short and
tall-narrow examples at desktop/mobile widths, plus PR-base renderer comparisons
with the same cached catalog/art. Local browser launch is unavailable in the
execution sandbox; visual review relies on CI artifacts. Original/cutout bytes
and provenance are unchanged; no asset checksum refresh is needed.

No prototype elements were omitted. This is a focused spacing correction;
per-specimen enlargement or replacement artwork is outside its scope.
