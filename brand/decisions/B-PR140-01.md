# Półtawski default with retained serif selection

The owner directed: “Make poltawski the default serif font, but keep the selector
around (unless there are serious counter arguments like load on the browser or
security issues).” Both alternative families already use regular 400 by direction.

This partially replaces B12's default Fraunces family and B-PR135-01's opt-in-only
selector/default behavior. Their historical records remain intact. Półtawski Nowy
is the default for every serif role, including the wordmark, at regular 400 with
normal variation settings. Commit Mono, type sizes, spacing and artwork are
unchanged. Fraunces retains 300/600 and SOFT/WONK axes when selected; Instrument
Serif retains 400. The hosted selector is always visible on supported current
routes. URL choices travel across navigation without persistent browser storage.
Reset removes the parameter and restores Półtawski. Offline editions embed only
Półtawski and Commit Mono and omit the hosted selector.

There is no serious security objection: fonts remain same-origin, pinned,
licensed WOFF2 files, with no external font service, credentials, new permissions
or dynamically evaluated source. Existing Fraunces and Commit Mono WOFF2 bytes
are extracted unchanged from the previous embedded bundle. Separate CSS faces
let the browser request only the chosen serif. The small early initializer
applies explicit URL choices before content renders, avoiding an unused default
font request; content-hashed URLs keep script, font CSS and tokens current.
Without JavaScript, shared tokens and CSS still select Półtawski. Font failure
leaves a readable system serif and a status message rather than hiding content.

The default serif payload is 124,040 bytes versus 194,976 bytes for Fraunces,
previously base64-embedded in every font stylesheet. Commit Mono remains 86,748
bytes. The selector adds a small script/style/control, while separate font files
are cacheable and avoid transmitting unused serif families. Selecting another
family intentionally downloads that family. Offline output retains complete
font bytes and licenses, with no network font dependency.

## Requested bold support

On 2026-10-19 the owner additionally requested the Półtawski bold cut. The existing
124,040-byte WOFF2 has a genuine wght axis from 400 through 700. Hosted and offline
CSS expose that range, allowing explicit bold/700 styling while retaining regular
400 defaults, the selector and the existing no-synthesis rule. Font bytes and
licenses are unchanged; no italic cut or global heading-weight change is added.
