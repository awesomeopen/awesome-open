# QR-height specimen label and one trophy line

The specimen label is about as tall as its QR code. It lists the header
("Awesome Open* · Field record", or "Archived on GitHub"), name, Registry ID ·
Folio, Domain, and "Specimen: Name" as the permalink. Each fact takes one line at a
tight leading and is cut with an ellipsis rather than wrapped. The permalink keeps
its "Permalink to Name" accessible name. The label sits below the drawing
(`margin-top: 0`) instead of overlapping it by 4em.

Scoreboard places leave the label. One link under the Function statement reads
"N Trophies" (or "1 Trophy") with the `rank.trophy` cup. It links to the Scoreboard,
or to the one board for a single place; its title lists each board, place and the
edition's update date.

Rationale: owner review on 2026-11-15. The per-board links showed "1 Stars", which
read as a GitHub star count. Checked on all 584 plates at 1440 × 900: no label is
taller than its QR code and no line is cut.

This changes the label overlap and contents in the
[specimen plate rules](../visual-system.md#specimen-plate-for-every-record-b29) and
the plate trophy links in the [Scoreboard contract](../../site/SCOREBOARD.md).
