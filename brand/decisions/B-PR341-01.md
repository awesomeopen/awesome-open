# Repository language evidence

Use the reserved three-column plate box between Release record and Where it runs
for Repository languages. Three leading names keep the plate compact; the native
disclosure gives the full GitHub byte breakdown, dates, cache status and source.
Keep the existing white evidence-box treatment, keyboard disclosure and static
record. The box remains visible at narrow widths.

The owner requested language evidence on plates, in filters and in WebMCP, and
suggested a reserved verdigris block. This placement groups source composition
with release and setup evidence without changing their meanings. It is a partial
extension of [the fixed grid](B-PR158-01.md); its other reserved block remains.

The [language contract](../../site/REPOSITORY-LANGUAGES.md) defines missing, empty
and stale observations, any-member filtering, full assistant evidence and the
existing publisher's bounded refresh. Non-GitHub projects stay unknown. Collection
uses repository bytes; runtime requirements and API support have separate sources.
No artwork, font, icon, skill pin, reviewed description or schedule changes.

Implementation and visual review: [PR #341](https://github.com/awesomeopen/awesome-open/pull/341).
