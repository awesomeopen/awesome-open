# Plate specimens ship 512/768 px display variants

Phase 3b of the [performance PRD](../../PRD/2026-10-22_Performance-tuning.md#w4-payload-reduction-phase-3),
in its own PR as [B-PR184-02](B-PR184-02.md) requires.

## Decision

Each specimen plate's image (the cut-out, or the original where no current
cut-out exists) gets 512 and 768 px wide WebP variants. The plate's `<img>`
lists them with the source in `srcset`, with
`sizes="(max-width: 660px) 100vw, 627px"`; 627 px is the plate stage's widest
extent. The loupe keeps magnifying the source, because it draws the image at
twice the plate width. Detail crops use the image the browser chose; they draw
the whole image at 218–336 CSS px.

Static records and ledger drawers share this markup. The drawer loader now
accepts `srcset` on images when every candidate resolves to the site's origin
with a `w` descriptor, and rebases each candidate like `src`.

## Files and provenance

- 364 variants for 182 sources in `site/specimens/responsive/`, 26.6 MB:
  512 px averages 47 KiB and 768 px 95 KiB. The shown sources average 246 KiB.
- `site/specimens/responsive.json` records each source's hash and dimensions,
  each variant's path, size, bytes and hash, the recipe (Lanczos, WebP q85,
  method 4, the hero's recipe) and the tools (Pillow 12.3.0, libwebp 1.6.0).
- `scripts/build_specimen_variants.py` regenerates only entries whose source
  changed. The build uses a source's variants only while its hash matches, and
  stops on variant bytes that differ from the manifest.

Pixel review on 2026-10-23: six sources across originals and cut-outs, compared
at 400 px against their source; colour, line work and transparency match. A
3× close-up shows softening at 512 px, which phones display at about 390 CSS px.

## Effect

At 1× DPR a phone loads the 512 px variant and a desktop the 768 px variant in
place of the 1024–1254 px source. At 2× a phone's plate (about 380 CSS px) takes
the 768 px variant; at 3×, and on desktops at 2×, the browser still selects the
source.

The site grows by 26.6 MB: the average specimen bytes per illustrated project
rise from 409 to 552 KiB, and the size budget's limit moves to 640 KiB. Whether
both the original and the cut-out need to ship is a separate open item of the
performance PRD; dropping originals shown nowhere would more than offset this.
