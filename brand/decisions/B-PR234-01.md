# Compact Scoreboard rows and labels

[PR #234](https://github.com/awesomeopen/awesome-open/pull/234) implements the
requested headings: “Most names”, “Longes HN streak”, “Most HN stories”, and
“Most GitHub stars”. These are rendering labels; frozen evidence retains its
existing schema, titles and measurement definitions.

Each row shows place, project and count on one line. Long project names truncate
with an ellipsis and retain full names in titles. The numeric count is the
marker-free, underlined native evidence control, opening an overlay with sources
and retained-cache status. Units appear once in table headers. Native keyboard
and no-JavaScript disclosure behavior remain available.

The Edition and coverage section is removed. Per-board methods and snapshot
download remain available. The footer says “Return to Catalog” and the heading
omits the introductory tagline.

Validation includes weekly Scoreboard tests, an offline preview build and brand
integrity. Browser visual review remains pending.
