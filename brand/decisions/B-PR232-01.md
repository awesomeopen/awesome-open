# Publish validated new specimen artwork without aesthetic sign-off

The owner directed on 2026-10-31 that technically valid new illustrations should
proceed to publication without waiting for individual or batch aesthetic review;
later replacements remain specific owner requests. This implements that direction
as a narrow exception for discovery and backfill new-artwork-only PRs.

The [specimen handoff](../../site/SPECIMEN-ART.md#publication-after-validation)
defines the complete gate: actual pixel inspection; technical, identity,
provenance, rights and safety checks; recoverable original artifacts before
upload; required offline/build/browser validation; exact-head CI; scoped remote
diff and preservation of owner edits. After those pass, the agent may mark ready
and merge the verified expected head. The existing publisher and Pages output
must then be verified before reporting live coverage.

This replaces only the separate owner publication checkpoint for new artwork.
The existing default display approval and nonblocking aesthetic notes remain.
One in-flight backfill batch prevents duplication rather than waiting for
aesthetic sign-off. Existing assets and historical statuses are preserved;
regeneration requires a specific request.

No PR approval review, auto-merge configuration, branch-protection bypass,
credential, workflow or security change is authorized. Required independent
approval and unavailable or failed validation remain blockers. Policy and
mixed-scope PRs, including [this proposal](https://github.com/awesomeopen/awesome-open/pull/232),
retain owner review. Other enrichment jobs and all schedules are unchanged.

The [automation inventory](../../automation/README.md#backfill-specimen-artwork)
and [contribution guide](../../CONTRIBUTING.md#source-previews-and-publication)
carry the same boundary. Repository documentation does not itself change a
hosted job's instructions; its operator must reconcile those separately.
