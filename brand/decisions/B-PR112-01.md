# Hide the full-record fallback after a successful drawer load

Keep the full-record link visible when JavaScript is unavailable, while a record
loads, and on failure. Hide the line once the native drawer has successfully
loaded its plate. This removes the extra line above the specimen without
removing the no-JavaScript and error-recovery route.

Use the native hidden attribute so the hidden link leaves both the visual layout
and keyboard navigation. If that link holds focus when loading finishes, return
focus to the native summary before hiding it. Cache eviction restores the link.

This partially changes the fallback visibility described in
[B-PR111-01](B-PR111-01.md). The loaded ledger no longer presents the direct
print-route link; static record pages and the downloadable standalone remain
printable. Artwork, plate content, identity, tokens and loading retention do not
change.

Implementation and review evidence: [PR #112](https://github.com/awesomeopen/awesome-open/pull/112)
and the [loading contract](../../site/DETAIL-LOADING.md). The draft implements the
requested visibility adjustment and remains pending review.
