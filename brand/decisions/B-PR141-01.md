# Jar callout colors and Inspect link treatment

User-directed changes implemented for review in [PR #141](https://github.com/awesomeopen/awesome-open/pull/141),
based on source `91abdd8a10d4689cc2fcf2bdf36f5be3f3868c3a`:

- Jar function text spans use `#ffc800`; repository metric spans use `#D9EEF8`.
- Rename the callout link from Inspect record to Inspect, matching its
  third-activation accessible label.
- Remove the visible dashed resting border. Show a 3px solid border on hover
  and keyboard focus, reserving a transparent 3px border at rest to prevent shifts.

This revises the existing Inspect-link and jar-callout treatments.
The colors are bounded callout backings, not a global palette change. Project
links, crack progression, drawer opening, specimens and image bytes are unchanged.

Validation: production/offline hero tests, syntax checks, brand integrity and
whitespace. Browser checks are updated to assert both backgrounds, Inspect copy,
transparent resting border, 3px hover border and stable dimensions; browser visual
execution is unavailable in this environment.
