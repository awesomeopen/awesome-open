# Weekly Scoreboard and metric-specific specimen trophies

Add a dedicated `/scoreboard/` route, using the Observatory's B42 shell, for six
Top 10 rankings from collected evidence. Observatory retains its interactive
snapshot exploration; Scoreboard keeps a stable weekly edition and links each
ranked project to its specimen record.

The owner requested Top 10 measurements, places 1–3 with small trophies repeated
on specimen plates, and a weekly cadence. This implementation proposes the
specific metric, tie and publication rules in the [Scoreboard contract](../../site/SCOREBOARD.md).
The [draft implementation](https://github.com/awesomeopen/awesome-open/pull/227)
is the review record; technical validation does not establish design acceptance.

Instrument: six ruled, comparable tables with values, units, qualifying counts,
visible section navigation and native evidence disclosures. Specimen: existing
canonical record links and unchanged illustrations. Editorial hand: one outlined
16px cup beside a place numeral. Tied values share the same competition place;
all cutoff ties are shown. Plate links repeat the metric and edition, keeping
these places separate from existing category-star bolding.

The page reuses the white/Prussian system, Półtawski headings, Commit Mono evidence,
Observatory gutters/header/footer and ordinary keyboard controls. The icon is
code-authored on its own pixel grid, registered in both icon maps and provenance.
No new specimen, external illustration or generated-image dependency is added.

The existing normal publisher freezes the current week's cached measurements,
with dates and source fingerprints. Same-week reruns and cached repairs preserve
that edition. The latest snapshot is kept; Git retains previously published
versions. An absent snapshot leaves an explicit first-publication state and no
trophies. A separate explicit preview option is visibly provisional and cannot
be combined with production output. There is no additional collector or schedule.

Coverage limits are carried by the measurement: repository creation is dated as
such; release gaps use published full releases and last push; HN has a stated
24-completed-month matching window; rename counts cover reviewed software-name
events. Missing evidence is excluded. Recorded names and official-source links
remain in frozen rows when projects leave the catalog; trophies attach only to
current canonical IDs.

No prototype or image comp was supplied. The implementation extends the current
route shell rather than replacing it. Independent source review caught and fixed
an inherited mobile rule that hid section links. Local Chromium could not start
under the execution environment's socket restriction; exact-revision CI browser
artifacts supply the remaining visual evidence, reported in the PR.
