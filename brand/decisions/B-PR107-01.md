# Timeline event anchors and Catalog naming

User-directed correction to B43’s close-date timeline behavior: keep literal
marker positions, place creation text 8px left of its marker with right alignment,
and push text 8px right with left alignment. The labels no longer attach to
opposite timeline edges. The existing close-date threshold remains.

Use Awesome Open* Catalog and Awesome Open* Observatory as page titles, Catalog
in top navigation, and the catalog footer’s `#about` as the About destination.
Rename the visible weekly draw archive to Spotlight while retaining `/draws/`.
Shorten the requested Scorecard, stars and artwork notes; put the stars note
immediately below HN and GitHub before Top. Evidence links and data stay intact.

This partially updates B43 and the sibling route shell; artwork, tokens, metrics
and selection rules do not change. Implemented for review in
[PR #107](https://github.com/awesomeopen/awesome-open/pull/107).
