# Icon-triggered detail popovers on the specimen plate

User-directed follow-up to B-PR144-01 in [PR #146](https://github.com/awesomeopen/awesome-open/pull/146).
B-PR144-01 tightened the plate and the evidence boxes, but the owner still finds
the presentation too scattered. The owner keeps the plate's open, airy character
and its distance from a literal wooden specimen drawer. The new aim is to fit
more of a record into the viewport.

Minor details move one click away. The trigger is the icon from the
[icon map](../icons.md#plate-detail-popovers) that already restates the
detail's label: a `state.*` glyph for retrieval history, `review.current` for
review sources and dates, `control.info` for definitions. The paired label stays
visible, so no evidence label is replaced by an icon alone. The popup is small
and ends with links to external sources (`link.external`) or evidence files
(`link.data`). It does not lead to another page on the site.

Rules from the icon map still apply. Unknown is not negative, colour never
carries state alone, and no icon adds a verdict. Evidence order and source data
stay as they are.

Owner answers to the review questions, recorded in the icon map:

- No distinct popup affordance; plate disclosures carry no `+` marker.
- Popups size to content, capped at 90% × 90% of the viewport, with internal
  scrolling and a close button pinned at the top.
- Without script, offline and in print, every detail is written inline under its
  box (title, data, additional data). Script only hides and wires it.
- Triggers start with the 16px glyph in a 24px button; the 12px glyph is tested
  where space is tight. Glyphs are not scaled across their drawn sizes.

Map correction: `disclose.open` was documented and drawn as a minus, while the
site uses the approved upright asterisk for open ledger rows and data notes. The
row in both map files, the two SVGs and the icon provenance now follow the site.
This corrects documentation to an existing rule; it changes no site behaviour.

## Implementation in this PR

`scripts/plate_detail.py` writes each detail as a visible label, an icon
trigger and an inline panel. `site/catalog.js` hides panels only when a native
`<dialog>` is available and opens their content in one shared dialog via a
delegated click, so fetched record plates need no extra wiring. Print shows
panels inline. Pages carry one hidden icon sprite; the standalone edition points
plate evidence links at the footer's single embedded copy of each file.

Moved behind triggers, one popup per box (see the
[icon map table](../icons.md#plate-detail-popovers)): Release and Scorecard
check lists, commit and retrieval history; star-history window, scale and
retrieval history; the HN window and scale (`control.info`, now `today`);
function summary sources; alternative scope; name-change evidence; stale or
unavailable metrics notices; and the setup facts behind “Where it runs”.
“Feature source” ends with the `link.external` glyph. Band spacing on the plate
drops from 64px to 40px (48px to 32px at 720px and below).

Changed from the proposal:

- One trigger per evidence box instead of separate triggers for Scorecard checks
  and retrieval history, following the owner's “title, data, all additional
  data” order.
- Setup facts moved into a popup (the proposal had kept their disclosure).
- Registry ID and Folio number keep their `title` text; an info button in the
  label adds clutter for a one-line definition.
- The departure “↗” stays typographic: it is a display-size `--rs-scarlet-art`
  mark, and the ink glyph would change an approved visual.
- A provider that returned no result shows `state.none`, not `state.failed`.

Measured on the OpenTofu record (most details in the catalog), main `20286c7`
against this branch, Chromium: plate height 2,800 → 2,473px at 1440px wide
(−12%) and 4,021 → 3,483px at 390px (−13%); the evidence row 282 → 203px and
889 → 679px. The standalone file grows 96.1 → 97.7 MB for 523 plates.

Status stays proposed until visual review. Exact checks and limits are in
[PR #146](https://github.com/awesomeopen/awesome-open/pull/146).
