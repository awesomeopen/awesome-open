# Repository host names in specimen departures

The user approved host-aware departure copy for implementation in
[PR #157](https://github.com/awesomeopen/awesome-open/pull/157).
Recognized repository destinations read “Explore [name] on [host]”.
Homepage and unrecognized destinations read “Explore [name]”.

The canonical catalog URL remains the destination. Exact host and repository
path recognition covers GitHub, GitLab, Codeberg, Bitbucket and SourceForge.
An explicit reviewed mapping identifies OpenGeoSys's canonical
`https://gitlab.opengeosys.org/ogs/ogs` destination as GitLab. Further self-hosted
repositories need explicit mappings. Platform names remain independent of
metrics collection capabilities.

This refines the departure copy in B10 and B29. See the
[plate contract](../visual-system.md#specimen-plate-for-every-record-b29).
Catalog identities, evidence, layout and artwork retain their existing behavior.
Rendered-link regression checks cover supported platforms, self-hosted GitLab,
homepages, unknown repositories, lookalike domains and escaped project names.
