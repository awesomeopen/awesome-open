# URL-only serif preview comparison

The owner requested a whole-site comparison retaining Fraunces, and directed both
Instrument Serif and Półtawski Nowy to use regular 400 throughout. This draft
implements that bounded experiment; it does not replace the default typography
in B12 or claim approval of either candidate.

The explicit `serif` URL parameter enables a labeled selector across the hosted
catalog, fetched plates, individual records, Observatory, Weekly draws and design
reference. Plain URLs retain Fraunces 300/600, its axes and Commit Mono. Alternate
families use 400 in all serif roles and clear Fraunces-only axes, while preserving
existing type sizes, spacing and monospaced text. The choice follows internal
page navigation and filters, with no browser storage preference. Exit preview
removes the parameter. Downloaded offline editions stay self-contained/default.

Candidate WOFF2 files are separate, loaded only when selected, with failure
falling back to Fraunces and an explicit status. The existing embedded base-font
bundle is retained. Default visitors pay only for the small opt-in detector,
not either candidate font or preview stylesheet. Source fonts and license
notices come from a pinned Google Fonts revision; conversions preserve outlines
and character sets. See [provenance](https://github.com/awesomeopen/awesome-open/blob/f0007445529b439372d2cc84e59556e58e5263d0/site/vendor/serif-preview/provenance.json),
[Instrument license](https://github.com/awesomeopen/awesome-open/blob/f0007445529b439372d2cc84e59556e58e5263d0/site/vendor/serif-preview/instrument-OFL.txt),
[Półtawski license](../../site/vendor/serif-preview/poltawski-OFL.txt), and
[preview instructions](../../site/PREVIEW.md#opt-in-serif-comparison).

Verification covers defaults, loading failure, regular weights, URL filters,
Back/Forward, internal navigation, keyboard controls and narrow layouts. Exact
results and tested source revision belong in [PR #135](https://github.com/awesomeopen/awesome-open/pull/135).
