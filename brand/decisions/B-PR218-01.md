# Compact jars and empty-search recovery

[PR #218](https://github.com/awesomeopen/awesome-open/pull/218) implements the
user-directed 808px maximum jar-stage width. Names longer than 11 characters
show those characters followed by an ellipsis, with the current Catalog folio
on the next line. Full names remain available in title and accessible controls.
Every jar uses `--rs-emerald-art` for hover light and vapor.

The plate's final heading reads “Explore”; its link reads “[name] on [host]”
or “[name]”, preserving the repository-host mapping. This changes the departure
copy within B29 and the caption treatment within B19.

Empty results read “No matches found.” With a category or evidence filter,
append the linked “Reset filters.” Reset retains the search query, selects All,
clears filters and reruns the search. Sorting alone does not restrict results.

The offline build and focused unit tests verify output and reset behavior.
Local browser verification is unavailable because the Chromium download is
truncated; the PR's browser workflow provides further validation.
