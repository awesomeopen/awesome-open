# Historical inputs

These files explain the design's evolution. They are not the current brand rules.

- `retro-scraperism-original.md`: the original warm-paper/mechanical brief, read
  from the owner's Library. Its parchment, wax seals and four-voice typography
  were superseded by the project guide.
- `concept-spine-original.md`: the original field-guide proposal. The specimen
  premise informed the project; invented motive, license-sincerity and health
  classifications remain proposals and must not be treated as evidence.
- `source-records.json`: original filenames, captured dates, body hashes and
  repository archive paths. Archive text after the status banner is unchanged.

Earlier implementation rationale remains at `site/DESIGN.md` and
`site/design_plan.md` so existing references continue to resolve. Earlier preview
routes/branches remain documented in `site/PREVIEW.md` as history. Do not restore
their obsolete directions simply because a file is still present.
