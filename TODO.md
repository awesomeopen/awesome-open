# Project ideas and decisions

Format: `YYMMDD - Idea - Status - Explanation / Problem`.
Dates are the dates recorded here, not necessarily when an idea was first proposed.
This is a manually maintained, non-exhaustive log; acceptance of an idea does not
by itself authorize implementation, a new schedule, or publication. Update statuses
when decisions or implementation change. Detailed design rules remain in the
[brand decision register](brand/decisions.md); evidence requirements remain in the
linked contracts.

- 261018 - Specimen audio: cloned name voice plus ambient scene - PROPOSED - Interpretative TTS character voices failed in local tests (Maya1, Qwen3-TTS VoiceDesign, VoxCPM2); see [specimen voice plan](site/SPECIMEN-VOICE-PLAN.md#outcome-experiments-failed). Next path: a friend's cloned voice reads the plain name (documented consent required), over a quiet background scene (bird song, wind, office, factory, train station) chosen from an interpretation of the tool's vibe. - 261018 - Frozen-in-time ex-Open* specimen page - PROPOSED - Add a page similar to Observatory for software that has fully renamed away from Open, preserving the last-known-to-us details for investigation. Consider a dated snapshot, source provenance, the reason for archival and a successor link when known; clearly distinguish frozen evidence from current facts. A repository-only rename does not establish a software-name change. Not implemented.
- 261016 - Optional Open-prefix exclusion in search - PROPOSED - Consider excluding the initial "Open" name-prefix from search matching, perhaps via a checkbox shown when the search input receives focus. With it enabled, searching "Open" would still match names such as "OpenOpen", whose remaining name contains "Open", instead of matching every name solely on its prefix. Interaction with other search keywords, including how they could dilute this effect, remains to be clarified. Not implemented.
- 261016 - Illustrations-only gallery - PROPOSED - Add a page similar to Observatory or Spotlight (Weekly) that lists only the illustrations in a simple grid on one long page. Not implemented.

- 261013 - Bus Factor / contributor concentration - REJECTED - Too interpretative for this catalog's factual signals; contributor concentration must not become a project-health or continuity verdict. Rejected as a product idea, not because the raw data is impossible to collect.
- 261013 - Downstream package counts - ACCEPTED IDEA - Worthwhile as an optional, qualified adoption signal and a smaller first step than a dependency filter. Separate dependent packages from upstream dependencies; record package, ecosystem, version, coverage and last-checked date, with unavailable counts Unknown rather than zero. Implementation remains to be designed.
- 261013 - Include / avoid dependency filter - UNDER ASSESSMENT - Find downstream projects that use a chosen tool, or include/avoid an upstream dependency or integration, such as Ollama. Distinguish Requires, Optional integration and Unknown; runtime/API relationships may be absent from package graphs. Require versioned sources, direct/transitive scope and checked dates; track releases, commits and lockfiles. A worthwhile filtering direction under assessment, separate from counts; no implementation or new schedule is approved.
- 261013 - Package download counts - EXPLORATORY - Downloads can include CI, mirrors and repeat installations. Define ecosystem-specific coverage and caveats before adopting a metric.
- 261013 - Stack Overflow mentions, response times and PR acceptance - DEFERRED - Identity matching, time windows and denominator definitions need work. These must not become a composite quality or health score.
- 261013 - License, CLA and foundation facts - UNDER CONSIDERATION - Prefer literal, source-backed facts.
- 261013 - Responsive hero images and compact catalog index - IN PROGRESS - Reduce image and initial catalog payloads while preserving the existing visual design, accessibility, search/filter behavior and evidence semantics. A separate implementation is being prepared for review.
- 261013 - HTMX, Alpine or fetch-based foldouts - UNDER CONSIDERATION - Explore loading expanded detail only when needed, with no-JavaScript behavior, permalinks and interaction reliability accounted for. No framework or loading strategy has been selected.
